## Building now

### [DealerIQ](https://www.dealeriq.ai/)

[![live](https://img.shields.io/badge/live-dealeriq.ai-c8f546?style=flat-square)](https://www.dealeriq.ai/)
[![case study](https://img.shields.io/badge/case%20study-read-c8f546?style=flat-square)](https://ahmad-portfolio-ten.vercel.app/work/dealeriq/)
[![stack](https://img.shields.io/badge/stack-FastAPI%20·%20Twilio%20·%20ElevenLabs-c8f546?style=flat-square)](https://ahmad-portfolio-ten.vercel.app/work/dealeriq/)

A real-time voice agent that picks up inbound calls for car dealerships. Audio streams through Twilio Media Streams into ElevenLabs, and routing runs on a deterministic rule engine with an LLM that can only veto, not decide, so a call never ends up somewhere the rules wouldn't allow.

The hard part was the handoff to a human. Warm transfers used to leave the caller in 10.3 seconds of silence; now the gap is under 100ms.

## Shipped

**[AI Recruitment Platform](https://ahmad-portfolio-ten.vercel.app/work/recruitment/).** The whole hiring pipeline in one place: LinkedIn publishing, CV parsing, AI voice interviews, scheduling and HR workflows. Every candidate gets a per-criterion scorecard, and proctoring issues get flagged for a human to review instead of auto-rejecting anyone.

**[StephanAI](https://x.lncaccelerator.com/).** A Claude-powered coach for a legal nurse consulting certification program, grounded in the program's own material through RAG. Knowledge base lives in pgvector, app data in plain PostgreSQL, so neither one gets in the other's way. Built on Next.js 15, React 19 and FastAPI.

**[Cloud Contact Center](https://pw-dev.dealeriq.live/).** Multi-tenant, with a dialer that embeds anywhere as an iframe. WebRTC and the Twilio Voice SDK underneath, reconnect logic for flaky networks, and Redis guarding lead assignment so two agents never grab the same lead.

**[Lead gen and browser automation](https://ahmad-portfolio-ten.vercel.app/work/leadgen/).** Scrapers built to survive the site changing under them: retries, session persistence and idempotent writes. Playwright, Selenium and BeautifulSoup, with n8n and Make on top.
